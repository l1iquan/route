第一版：川西小环线 4天3夜

成都往返不去梅里学生预算更友好

路线顺序

成都 → 四姑娘山/双桥沟 → 丹巴甲居藏寨 → 墨石公园 → 塔公草原 → 新都桥 → 红海子/鱼子西 → 康定 → 雅安 → 成都

每晚住宿

D1 住四姑娘山镇；D2 住新都桥；D3 住雅安；D4 返回成都。

适合原因

不绕去稻城和梅里，路程集中在川西经典小环线，预算、驾驶压力和高反风险都更可控。

每日安排

D1 成都 → 四姑娘山镇

上午从成都出发，经都江堰、映秀、卧龙到四姑娘山。下午游双桥沟或猫鼻梁看雪山。住四姑娘山镇。

D2 四姑娘山 → 丹巴 → 墨石 → 塔公 → 新都桥

早起离开，先看甲居藏寨，再经八美/墨石公园到塔公草原，傍晚到新都桥。住新都桥。

D3 新都桥 → 红海子/鱼子西 → 康定 → 雅安

天气好可去鱼子西或红海子，之后经折多山、康定回雅安。住雅安，住宿和餐饮比景区镇更省。

D4 雅安 → 成都

上午可选碧峰峡/蒙顶山短玩，下午回成都还车。赶高铁/飞机建议中午前离开雅安。

路段距离和时间

顺序路段距离自驾时间建议
1成都 → 四姑娘山镇/双桥沟约 200-230 km约 4-5.5 小时第一天早点走，避开都江堰、映秀拥堵。
2四姑娘山 → 丹巴甲居藏寨约 110-130 km约 2.5-3.5 小时山路较多，雨季注意落石。
3丹巴 → 墨石公园约 90-110 km约 2-2.5 小时若赶时间，墨石只短停拍照。
4墨石公园 → 塔公草原 → 新都桥约 60-75 km约 1.5-2 小时塔公草原适合看雅拉雪山方向。
5新都桥 → 红海子/鱼子西 → 康定约 80-120 km约 2.5-4 小时鱼子西日落后下山风险高，不建议夜路。
6康定 → 雅安约 190-220 km约 3-4 小时住雅安可降低住宿成本。
7雅安 → 成都约 140 km约 2-2.5 小时最后一天轻松返程。

第二版：丽江出发梅里雪山 4天3夜

丽江往返梅里雪山云南北线

路线顺序

丽江 → 虎跳峡 → 香格里拉/独克宗古城 → 奔子栏 → 德钦飞来寺/梅里雪山 → 白马雪山 → 松赞林寺/纳帕海 → 丽江

每晚住宿

D1 住香格里拉市；D2 住飞来寺；D3 住香格里拉市；D4 返回丽江。

适合原因

用 4 天把梅里日照金山放进来，同时不硬走雨崩徒步。第一次去梅里，飞来寺看雪山是最稳妥的玩法。

每日安排

D1 丽江 → 虎跳峡 → 香格里拉

上午丽江出发，游虎跳峡，下午到香格里拉。傍晚逛独克宗古城、龟山公园。住香格里拉市。

D2 香格里拉 → 奔子栏 → 飞来寺

经纳帕海、金沙江大湾或奔子栏方向北上，下午到德钦飞来寺。住飞来寺，等第二天清晨看梅里雪山。

D3 飞来寺日照金山 → 白马雪山 → 香格里拉

清晨看日照金山，上午可去雾浓顶或飞来寺观景台，随后经白马雪山返回香格里拉。住香格里拉市。

D4 香格里拉 → 松赞林寺/纳帕海 → 丽江

上午选松赞林寺或纳帕海环湖，午后返丽江。若要赶火车/飞机，建议不要安排太晚的景点。

路段距离和时间

顺序路段距离自驾时间建议
1丽江 → 虎跳峡约 80-90 km约 1.5-2 小时虎跳峡游览通常留 1.5-2.5 小时。
2虎跳峡 → 香格里拉市约 95-110 km约 2-2.5 小时下午到独克宗古城比较舒服。
3香格里拉市 → 奔子栏 → 飞来寺约 185-220 km约 4-5 小时山路和弯道多，尽量白天到飞来寺。
4飞来寺 → 雾浓顶/梅里观景台约 10-20 km约 20-40 分钟看日照金山要提前查日出时间。
5飞来寺 → 白马雪山 → 香格里拉市约 190-230 km约 4-5.5 小时高海拔路段，冬季注意结冰。
6香格里拉市 → 丽江约 170-184 km约 3-4 小时走香丽高速/国道组合，返程较稳定。

预算和选择建议

川西小环线

约 1300-2300 元/人，按 4 人分摊租车、油费、过路费估算。省钱关键是住镇上普通客栈、少进高价景区、雅安过夜。

丽江梅里线

约 1500-2600 元/人，丽江往返不涉及异地还车。飞来寺观景房会贵，学生预算可以订普通房，清晨步行去观景台。
